## 이 모음의 규칙
**모든 시안은 사용한 원샷 프롬프트, 모델, 만든 사람을 함께 공개합니다.** 결과만 보여 주면 따라 할 수 없기 때문입니다.

- 지금 있는 열두 개는 모두 [java-jaydev](https://github.com/java-jaydev)가 Claude Fable 5.2(`claude-fable-5-2`) 모델로, Claude Code에서 프롬프트를 한 번만 보내 만들었습니다.
- 보낸 그대로의 원문은 [prompts/](prompts/) 폴더에 있고, 우리말로 옮긴 것은 목록 페이지의 "프롬프트 보기"에서 볼 수 있습니다.
- 프롬프트를 보낸 뒤 사람이 손으로 고친 것이 있으면 그것도 적습니다.

## 알아 둘 것
- 열두 명은 모두 데모용으로 만든 **가상의 인물**입니다. 프로젝트, 수상, 연락처도 지어낸 내용입니다.
- 전주대학교와 공식 관계가 없는 개인 자료입니다. 전주대 학생이라고 가정하고 만들었을 뿐입니다.

## 내 포트폴리오로 바꿔 쓰기
1. 마음에 드는 시안의 HTML 파일 하나를 내려받습니다. 파일 하나에 디자인과 동작이 모두 들어 있어서 더블클릭하면 열립니다. (02번은 `Galmuri11.woff2` 글꼴 파일도 같은 폴더에 둡니다.)
2. 이름, 소개, 프로젝트 내용을 자기 것으로 바꿉니다. AI에게 "이 파일의 디자인과 동작은 그대로 두고 내용만 아래 내용으로 바꿔 줘"라고 시켜도 됩니다.
3. 새 방향으로 만들고 싶다면 목록 페이지에서 프롬프트를 복사해 인물과 방향만 바꿔 씁니다.

핵심은 **방향을 먼저 정해 주는 것**입니다. 색, 글꼴, 대표 장면 하나, 쓰지 말 것을 적어 주면 AI가 흔히 내놓는 평균적인 디자인에서 벗어납니다.

- 화면에도 출처 한 줄을 남겨 주세요. 예: 페이지 맨 아래에 `디자인 출처: github.com/java-jaydev/portfolio-styles`
- 고쳐서 쓴 경우에도 같습니다. "이 디자인을 바탕으로 고쳤다"고 적어 주면 됩니다.

## 내 포트폴리오 올리기
직접 만든 포트폴리오를 이 모음에 넣고 싶다면 환영합니다.

- **풀 리퀘스트**: 이 저장소를 포크해서 아래 네 가지를 넣어 보내 주세요.
  1. HTML 파일 하나
  2. `prompts/` 폴더에 프롬프트 원문 파일 하나
  3. `thumbs/` 폴더에 첫 화면 캡처 하나(가로 900px 정도의 jpg)
  4. `index.html` 안의 `ITEMS` 목록에 항목 하나
- **Git이 처음이라면**: [이슈](https://github.com/java-jaydev/portfolio-styles/issues)에 포트폴리오 링크, 프롬프트 원문, 모델 이름, GitHub 아이디를 남겨 주세요.

올리기 전에 확인해 주세요.
- **사용한 원샷 프롬프트 원문과 모델 이름을 반드시 함께 냅니다.** 이것이 없으면 받지 않습니다. 여러 번 고쳐 가며 만들었다면 그 사실과 고친 내용도 적습니다.
- **만든 사람의 GitHub 아이디를 적습니다.** 목록의 카드에 표시됩니다. 실명이나 이메일은 필요 없습니다.
- 본인이 만든 본인 포트폴리오만 올립니다.
- 올린 파일은 이 저장소와 같은 MIT 라이선스로 공개됩니다.
- 전화번호처럼 공개하고 싶지 않은 정보는 빼 주세요.
- 외부 라이브러리 없이 HTML 파일 하나로 열려야 합니다. 직접 열어 확인한 뒤에 받습니다.
